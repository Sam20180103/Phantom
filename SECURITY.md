# Security

For vulnerabilities specific to Phantom, use **Security > Report a
vulnerability** on the Phantom GitHub repository to report the issue privately.
Include the affected commit or version, your platform, the impact, and steps
to reproduce. Keep credentials and other private data out of the report.

For vulnerabilities specific to upstream Terax, follow the
[Terax security policy](https://github.com/crynta/terax-ai/security/policy).
